### 1.  입력 처리 (RacingGameService-startGame)
   - 자동차 이름 입력받기 (쉼표 , 기준으로 구분)
   - 시도 횟수 입력받기 
   - 입력값 검증 (자동차 이름 공백 여부, 시도 횟수 숫자 여부 확인)

### 2. 게임 진행 (RacingGameService-playGame)
   - 라운드 수만큼 게임을 진행하면서 자동차 이동 
   - 각 라운드 종료 시 자동차의 위치 출력

### 3. 자동차 이동 로직 (CarService)
   - 0~9 사이의 랜덤 숫자를 생성
   - 4 이상일 시 전진

### 4. 게임 종료 후 우승자 판별 (RacingGameService-overGame)
  - 게임 종료 후 최대값에 따른 최종 우승자 출력

### +  입력값 검증 (Validator)
  - 자동차 이름이 공백이면 예외 발생
  - 시도 횟수가 1 이상인지 검증 
  - 숫자가 아닌 입력값에 대한 예외 처리
